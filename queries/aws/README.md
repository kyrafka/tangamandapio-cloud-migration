# Consultas operativas AWS

Después de desplegar, abrir CloudWatch Logs Insights, seleccionar el log group que entrega el stack y ejecutar `portal_5xx_and_health.insights.sql`.

La evidencia debe mostrar el rango temporal, log group seleccionado y el resultado de la consulta. La consulta no sustituye la prueba funcional: se usa para correlacionar solicitudes de salud y errores del portal.
