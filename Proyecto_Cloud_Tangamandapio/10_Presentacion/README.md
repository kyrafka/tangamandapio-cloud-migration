# Sustentación

1. Mostrar la [arquitectura](../02_Arquitectura/README.md) y el [direccionamiento](../03_Redes/README.md).
2. Registrar un pedido sintético. Mostrar su identificador en el ERP y cotejarlo en Application Insights.
3. Mostrar destinos sanos y la actividad del autoescalado. Usar [los registros](../06_Pruebas/README.md) para carga y conmutación.
4. Mostrar [monitoreo](../07_Monitoreo/README.md), [restauración](../08_Backup_DR/README.md) y [costos](../09_Costos/README.md).
5. Cerrar con el alcance de [la reconstrucción con IaC](../04_IaC/README.md).
