## Límites de esta evidencia

La suite es local y no demuestra recepción real de notificaciones SNS, entrega
SMTP externa, inventario físico, llamadas WebRTC entre dos navegadores, ni
dominio/HTTPS público. El smoke Azure sí demuestra el procesamiento del ledger
ficticio, no una conexión a inventario comercial real. Tampoco sustituye la
revisión visual manual en navegador ni una verificación del despliegue AWS.

Se canceló un proceso local antiguo de `deploy.sh` que estaba esperando la
confirmación literal `APPLY` para un artefacto del 12/10. No se envió esa
confirmación ni se ejecutó `execute-change-set`; no se comprobó si el proceso
había alcanzado a dejar un change set preparado en AWS. Antes de publicar hay
que revisar el change set y regenerar el artefacto desde el código probado.
